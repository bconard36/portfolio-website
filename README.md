# Portfolio Website

Detail-oriented student graduating in Spring 2026 with an AAS in Web Development and Design along with a Database Design and SQL Certificate, with over seven years of background in leadership and communication. This website serves as a central hub to showcase my skills as a self-driven developer, with projects including multiple websites, designs, and UI/UX elements, and as a process-oriented analyst with projects highlighting SQL, Python, and visualization tools. 

## Features

- Responsive, mobile-first design for optimal viewing on all devices  
- Interactive JavaScript elements, including dynamic project and skills tiles that move and reveal text when hovered over, respectively, a welcome message that appears when a                'Click to Say Hi' button is clicked, and a button to toggle light and dark color schemes.  
- Organized layout highlighting projects and skills in web development, data analysis and professional experience   
- Integration of design portfolio to showcase visual work alongside coding projects
- A PDF version of my resume available for download at the bottom of the page  

## Tools & Technologies

- **HTML5 & CSS3** – Structure and styling of the website  
- **JavaScript** – Interactive elements and dynamic content  
- **Git & GitHub Pages** – Version control and website hosting  
- **Figma & Canva** – Design mockups, graphics, and portfolio assets  

## Purpose

This website serves as a professional portfolio to demonstrate my skills in web development, design and data analysis. It allows visitors to:  
- Explore my projects in web development, including an e-commerce website, and a fictional tour company website
- Explore my projects in data analysis, including SQL queries, Python statements and functions, visualizations with Tableau and Python tools  
- Learn about my professional experience, transferrable skills, technical skills and ability
- Connect with me via LinkedIn, GitHub, or email
- Download a copy of my resume for professional and networking purposes
